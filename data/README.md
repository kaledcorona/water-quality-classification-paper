# Data Description

The *Comisión Nacional del Agua* (CONAGUA) is the Mexican government agency responsible for managing, regulating, and protecting national water resources. Among its initiatives is the *Red Nacional de Medición de Calidad del Agua* (REMANECA), a nationwide network that monitors water quality through distributed sampling stations.

- 'raw/RESULTADOS-NUEVO LEÓN.xlsb': Unprocessed data extracted from CONAGUA website. In this document we refeer it as the 'original' dataset.
- 'processed/remaneca_nuevoLeon_datos.csv': Only the data sheet of 'raw/RESULTADOS-NUEVO LEÓN.xlsb', no more modifications or transformations.
- './processed/remaneca_nuevoLeon_simbologia.csv': the description of features sheet from the original dataset.
- './processed/remaneca_nuevoLeon_sitios.csv': the description of localization of sensing stations sheet from the original dataset without modifications.
- './processed/remaneca_clean.csv': modified dataset with selected features and through a cleaning process.

Data was extracted from CONAGUA ([link](https://www.gob.mx/conagua/articulos/resultados-de-la-red-nacional-de-medicion-de-calidad-del-agua-renameca?idiom=es)).
